# Stack Tower

A tap-to-stack mini-game built with Next.js + HTML Canvas.

## Game
- Blocks slide horizontally, tap/click to drop
- Overhang gets trimmed — stack shrinks over time
- Score = blocks stacked successfully
- At 500 points, reward modal with copyable code

## Tech
- Next.js (App Router)
- HTML Canvas for 60fps game rendering
- localStorage for best score persistence
- Mobile-friendly (tap + click)
